# Steam Cloud Manager

[English](README.md) · [Безопасность](SECURITY.md)

**Веб-приложение в проде**: [https://steam-cloud-manager.vercel.app/](https://steam-cloud-manager.vercel.app/)

Просмотр, резервное копирование и удаление сохранений Steam Cloud прямо в браузере без какой-либо локальной установки. Включает интерактивный демо-режим в 1 клик, официальный вход по Steam Guard QR, сессии с шифрованием AES-256-GCM, светлую/тёмную тему и полную локализацию на русском и английском языках.

## Основные возможности

- **Без скачивания и установки**: Полноценное веб-приложение, развёрнутое на Vercel по адресу [https://steam-cloud-manager.vercel.app/](https://steam-cloud-manager.vercel.app/). Работает в любом современном браузере на компьютере и мобильных устройствах.
- **Интерактивный демо-режим в 1 клик**: Исследуйте все функции менеджера на тестовых сохранениях (`Cities: Skylines II`, `ELDEN RING`, `Baldur's Gate 3`) без входа в Steam: просмотр библиотеки, скачивание файлов, экспорт в ZIP и безопасное двухэтапное удаление.
- **Официальный вход через Steam Guard QR**: Отсканируйте QR-код мобильным приложением Steam для безопасного подключения через серверные функции Fluid Compute.
- **Сквозное шифрование сессий (AES-256-GCM)**: Данные сессии запечатаны аутентифицированным шифрованием `AES-256-GCM` в защищённых `HttpOnly`, `SameSite=Strict` cookie. Сессии восстанавливаются на «холодных» инстансах без внешних баз данных.
- **Строгий периметр безопасности**: Защита от SSRF с DNS-pinning при скачивании из Steam CDN, потоковая проверка целостности SHA-1, криптографические CSRF-токены и проверка Origin.
- **Двуязычность и темы**: Полная поддержка русского и английского языков, автоматическое и ручное переключение системной, светлой и тёмной тем.

## Интерфейс приложения

При переходе на [https://steam-cloud-manager.vercel.app/](https://steam-cloud-manager.vercel.app/) сразу открывается веб-приложение:

1. **Войти через Steam QR**: Генерирует QR-код Steam Guard. Подтвердите вход в мобильном приложении Steam для управления личными облачными сохранениями.
2. **Попробовать демо-режим**: Один клик — и вы в интерактивной песочнице с тестовыми сохранениями. В верхней части отображается баннер активного демо-режима, а кнопка «Выйти» возвращает на экран входа.

## Библиотека и работа с сохранениями

- **Библиотека игр**: Отображает все игры с ленивой подгрузкой обложек из Steam CDN. Игры без классификации можно открыть вручную по AppID или ссылке Steam.
- **Избранное**: Хранится локально в браузере отдельно для каждого аккаунта.
- **Просмотр сохранений**: Детальный список файлов с датами изменения и точным размером.
- **Скачивание и ZIP-экспорт**: Скачивание отдельных файлов или создание ZIP-архива для выбранных файлов (до 500 штук) в один клик с потоковой записью на диск.
- **Безопасное удаление**: Удаление требует выбора файлов, закрытия игры и GeForce NOW, проверки актуальности файлов на сервере и точного ввода фразы подтверждения.

## Архитектура

Приложение работает на платформе Vercel в виде единого стека:

- **Фронтенд**: React 18 + Vite SPA (`src/client/App.tsx`), скомпилированный в `dist/client` и обслуживаемый в корне `/`.
- **Бэкенд**: Fastify на Node.js, адаптированный под Vercel Functions (`api/index.ts`) с технологией Vercel Fluid Compute (таймаут 300 сек).
- **GitHub Pages**: [https://famence.github.io/steam-cloud-manager/](https://famence.github.io/steam-cloud-manager/) автоматически перенаправляет пользователей на рабочее веб-приложение.

## Разработка

Для разработчиков доступен локальный запуск:

```sh
git clone https://github.com/famence/steam-cloud-manager.git
cd steam-cloud-manager
npm ci
npm run dev
```

Приложение откроется на `http://127.0.0.1:5173` с проксированием API на `http://127.0.0.1:3000`.

Запуск тестов и сборки:

```sh
npm run check              # Проверка типов, тесты и сборка
npm run test:browser:install # Установка Chromium для Playwright
npm run test:e2e           # Запуск сквозных E2E-тестов
```
